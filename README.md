# Bad Takes

A clapperboard app that reveals terrible takes one at a time with a satisfying snap animation.

Click the clapperboard to cycle through a collection of the internet's worst opinions.

## Getting started

```
npm install
npm run dev
```

## Adding your own takes

Edit `src/takes.js` — it's just an array of strings:

```js
const takes = [
  "Your hot take here",
  "Another scorching opinion",
];

export default takes;
```
